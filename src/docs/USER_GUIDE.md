# Руководство пользователя RQL Studio

RQL Studio — веб-приложение для работы со схемами доменов и составления RQL-выражений. Помогает писать правила данных, проверять их на реальных объектах, строить диаграммы связей и сравнивать версии схем.

## Быстрый старт

1. Откройте приложение.
2. Загрузите схему домена: перетащите `.yaml` файлы в левую панель или нажмите **Пример**, чтобы загрузить демонстрационную схему.
3. Выберите сущность в шапке в селекторе **Сущность**.
4. Переключитесь между вкладками **Код**, **Конструктор**, **Диаграмма**, **Симулятор** — каждая решает свою задачу.
5. Используйте **Cmd+K** (или Ctrl+K), чтобы найти сущность, связь или правило.

## Интерфейс

Приложение разделено на три области:

- **Слева** — Схема Explorer: список загруженных файлов, дерево сущностей, связей и правил.
- **В центре** — рабочая область с вкладками:
  - **Код** — редактор RQL с подсветкой, автодополнением и диагностикой.
  - **Конструктор** — визуальный построитель условий.
  - **Диаграмма** — граф сущностей и связей.
  - **Симулятор** — проверка правил на конкретном объекте.
- **Справа** — Инспектор: детали выделенного элемента.

В шапке — переключатель вкладок и кнопки **Отчёт**, **Валидация**, **Diff**, **Справка**.

## Загрузка схем

Схема — это YAML-файл, описывающий домен: сущности, атрибуты, связи, правила и другие элементы.

### Способы загрузки

- **Перетащите** один или несколько `.yaml` файлов в область **Схемы** слева.
- **Нажмите +** в шапке секции — откроется диалог выбора файла.
- **Нажмите Пример** — загрузится демонстрационная схема с двумя доменами.

### Редактирование

- **Клик по имени файла** — откроется редактор YAML в полноэкранной модалке.
- Редактор показывает подсветку синтаксиса, предупреждения и ошибки валидации схемы.
- Кнопка **Применить** пересобирает дерево сущностей.
- Кнопка **Скачать** сохраняет файл на диск.
- Кнопка **×** на строке файла — удаляет его из сессии.

## Схема Explorer

Секция **Элементы** слева показывает дерево загруженных схем. Три режима:

- **Сущности** — структура: домен → сущность → атрибуты + связи + правила.
- **Связи** — плоский список связей домена.
- **Правила** — список всех правил данных домена.

### Работа с деревом

- **Клик по сущности** раскрывает её атрибуты.
- **Клик по атрибуту** переключает контекст редактора на этот атрибут.
- **Hover на атрибут** показывает тултип с типом, ограничениями и правилами данных.
- **Ctrl+клик на атрибут** копирует его ID.
- **Иконка поиска** рядом с атрибутом — найти вхождения в текущем правиле.
- **Иконка «+»** на связи — добавить эту связь в конструктор одним кликом.

### Поиск

Поле поиска фильтрует содержимое по имени, ID или FQID. Регистр не важен.

## Редактор RQL

Вкладка **Код** — редактор Monaco с поддержкой языка RQL.

### Возможности

- **Подсветка синтаксиса**: ключевые слова, строки, числа, псевдонимы.
- **Автодополнение**:
  - `@doc.` — атрибуты текущей сущности;
  - `@e_X.` — атрибуты связанной сущности;
  - `@link_X.` — атрибуты связи;
  - `@enumX.` — значения перечисления;
  - функции RQL (`hasRole`, `TSRANGE`, `join`, ...);
  - системные псевдонимы (`@CurrentUser`, `@CurrentDate`).
- **Hover** по элементам показывает детали: тип атрибута, описание функции, свойства связи.
- **Диагностика** — подчёркивает ошибки и предупреждения:
  - синтаксические — красным;
  - семантические (несуществующий атрибут) — красным;
  - типовые (несовместимые типы) — красным;
  - потенциальные (неизвестный псевдоним) — жёлтым.
- **Quick Fix** по **Ctrl+.** — предлагает исправления для опечаток в именах атрибутов, значений перечислений и функций.
- **Форматирование** по **Shift+Alt+F** — приводит выражение к читаемому виду.

### Сниппеты

При наборе префикса (например, `link-exists`, `user-has-role`, `date-in-range`) редактор предлагает вставить готовый шаблон. Tab переключает позиции подстановки.

## Конструктор условий

Вкладка **Конструктор** — визуальный редактор правил без необходимости писать RQL руками.

### Основные блоки

- **Условие** — сравнение атрибута с значением.
- **Связь** — проверка наличия связи или условия на связанный объект.
- **Группа** — логическая группа `И` / `ИЛИ` / `НЕ`.
- **Вложенные группы** — можно вкладывать до любой глубины.

### Управление

- **+ Условие**, **+ Связь**, **+ Группа** — добавить элемент.
- **Свернуть / развернуть группу** — кнопка `▾` слева.
- **Дублировать условие** — иконка `⧉`.
- **Переместить** — стрелки `▲` / `▼`.
- **Удалить** — иконка корзины.

### Предпросмотр RQL

Внизу панели показывается сгенерированный RQL. Он обновляется автоматически при каждом изменении.

### Кнопки тулбара

- **Применить** — подставить RQL в редактор кода.
- **Сохранить** — записать правило обратно в YAML схемы (если открыто существующее правило).
- **Импорт** — разобрать RQL из редактора в дерево.
- **Отменить / Повторить** — Undo/Redo.
- **Объяснить** — показать человекочитаемое описание правила.
- **Шаблоны** — открыть библиотеку типовых правил.
- **Экспорт в YAML** — сгенерировать YAML-фрагмент.
- **⋯** — дополнительные действия.

### Полоса контекста

Над тулбаром — тонкая полоса с текущим правилом и доменом, а также индикатором «Сохранено / Не сохранено».

## Шаблоны правил

Модалка **Шаблоны** содержит библиотеку типовых правил данных:

- **Обязательность** — поле обязательно, если другое заполнено; обязательно для статуса.
- **Скрытие** — скрыть поле для статуса; показать только для статуса.
- **Запрет редактирования** — readonly для заполненного поля; readonly после закрытия.
- **Пользователь** — значение по умолчанию; редактирование только автором.
- **Даты** — дата не в прошлом / не в будущем.
- **Валидация** — числовой диапазон; ограничение допустимых значений.
- **Связи** — требовать наличие связи указанного типа.

Каждый шаблон имеет две группы параметров:

- **Условие правила (RQL)** — что должно быть выполнено.
- **Эффект правила (dataRules)** — какой атрибут и как меняется.

Справа показывается предпросмотр — сгенерированный RQL и YAML.

---

## Экспорт в YAML

Модалка **Экспорт в YAML** генерирует фрагмент `dataRules` для вставки в схему.

Параметры:

- ID правила,
- Название,
- Эффект (`required`, `hidden`, `readonly`, `default`, `allowed`),
- Целевой атрибут,
- Сообщение об ошибке,
- Справка.

Справа — YAML в реальном времени. Кнопка **Скопировать** — в буфер, **Скачать** — в файл.

## Диаграмма связей

Вкладка **Диаграмма** — визуальный граф домена.

### Возможности

- Сущности — узлы, связи — рёбра.
- Цвета рёбер по типу: 1:1 (зелёный), 1:N (синий), N:N (оранжевый).
- **Клик по узлу** — фокус на сущности в Explorer.
- **Двойной клик** — открыть сущность в конструкторе.
- **Клик по ребру** — показать связь в инспекторе.
- **Hover** — детали в тултипе.
- **Поиск** по узлам — центрирует граф на найденной сущности.
- **Группировка по доменам** — сущности одного домена в рамке.

### Управление

- **Домен** — фильтр по домену.
- **Раскладка** — горизонтальная или вертикальная.
- **Группы** — включить группировку по доменам.
- **Пересобрать** — применить автораскладку заново.
- **Экспорт** — сохранить диаграмму в PNG или SVG.

Позиции узлов сохраняются автоматически. Кнопка **Пересобрать** сбрасывает их.

## Симулятор правил

Вкладка **Симулятор** — проверка правил на конкретном объекте.

### Как работает

1. Выберите сущность в шапке.
2. Введите JSON объекта или нажмите **Сгенерировать** для автозаполнения.
3. Укажите контекст — пользователя, роли, дату.
4. Симулятор покажет:
   - какие правила сработали;
   - какие атрибуты стали обязательными, скрытыми, readonly;
   - какие значения не проходят валидацию.

### Табы

- **Данные** — JSON-редактор + подсказки по значениям.
- **Связи** — значения связанных объектов.
- **Правила** — список правил с описанием эффекта.

### Подсказки

Панель **Подсказки по значениям** показывает варианты для полей enum, bool, дат. Клик вставляет значение в JSON.

## Сценарии и плейбуки

### Сценарии

Сохранённые наборы данных для повторного использования. Из меню **Сценарий** можно:

- сохранить текущее состояние как новый сценарий;
- переключиться на другой;
- обновить текущий;
- дублировать;
- удалить.

### Плейбуки

Плейбук — цепочка шагов, описывающая жизненный цикл объекта: создан → в работе → закрыт.

- Каждый шаг хранит свой JSON, контекст и список правил.
- Стрелки «← / →» в шапке шага перемещают по цепочке.
- Баннер над шагом показывает изменения от предыдущего.
- Кнопка **Скачать .md** экспортирует плейбук в Markdown.

## Отчёты

Модалка **Отчёт** генерирует документ по домену в форматах Markdown и HTML.

Разделы отчёта:

- Обзор домена,
- Сущности и атрибуты,
- Связи,
- Перечисления и workflow,
- Правила данных,
- Действия и меню,
- Кросс-доменные ссылки,
- Диаграмма связей в ASCII.

Каждый раздел можно включать или отключать. Результат — файл `.md` или `.html` со стилями.

## Валидация схем

Модалка **Валидация** проверяет схемы на типичные проблемы:

- сущности без name или label;
- атрибуты без имени;
- ссылки на несуществующие сущности в связях;
- циклы в наследовании;
- дубликаты ID правил, сущностей, атрибутов;
- ограничения `min > max`;
- правила с ссылками на несуществующие атрибуты;
- осиротевшие последовательности;
- неиспользуемые перечисления.

Проблемы группируются по домену и фильтруются по уровню: ошибки, предупреждения, информация. Клик по проблеме — переход к сущности в Explorer.

Отчёт можно **скопировать** или **скачать** в формате Markdown.

## Diff версий схемы

Модалка **Diff** показывает, что изменилось между двумя версиями домена.

### Как работает

1. Выберите левый и правый источник — загруженный файл или новый YAML.
2. Diff покажет:
   - **Добавленные** элементы (зелёный `+`),
   - **Удалённые** (красный `−`),
   - **Изменённые** (жёлтый `~`).
3. Разделы: сущности, атрибуты, связи, правила, типы, последовательности.
4. Раскройте сущность, чтобы увидеть изменённые атрибуты.

Фильтры сверху позволяют показать только добавленные, удалённые или изменённые элементы.

## Командная палитра

Открывается по **Cmd+K** (или Ctrl+K). Позволяет быстро найти и открыть:

- **Сущность** — переход к ней в Explorer.
- **Связь** — фокус на связи.
- **Правило данных** — переход на вкладку «Правила».
- **Файл** — открыть YAML в редакторе.
- **Действие** — переключиться на вкладку, открыть отчёт, валидацию и т.д.

Навигация: стрелки ↑↓, Enter — открыть, Escape — закрыть.

## Горячие клавиши

| Клавиши | Действие |

| **Cmd+K** (Ctrl+K) | Открыть командную палитру |

| **Ctrl+клик по связи** | Скопировать ID связи |
